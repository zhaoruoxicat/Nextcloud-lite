# Nextcloud 精简版

基于 **Nextcloud 35.0.1** 修改的精简版本，面向 CPU、内存和存储资源较有限的服务器，主要用于个人或小规模自建云盘。通过移除部分非核心应用，减少附带功能与维护负担，保留文件管理及相关应用。

本项目为自行修改版本，非 Nextcloud 官方发行版。精简不代表降低 Nextcloud 的基础运行要求；实际资源占用取决于用户数量、文件规模、预览任务和启用的应用，尚未进行性能对比测试。

## 主要功能

- 文件上传、下载与管理
- WebDAV 访问与客户端同步
- 文件分享与联邦分享
- 图片、PDF 等文件预览及照片管理
- 回收站与文件历史版本
- 用户管理、系统设置与主题配置

当前 `apps/` 目录保留 15 个应用，具体功能以安装后启用的应用为准。

## 运行环境

- PHP 8.3–8.5，并安装所需扩展（见 `composer.json`）
- Apache 或 Nginx，配置 PHP 支持
- MySQL、MariaDB、PostgreSQL 或 SQLite，以及对应的 PHP 数据库驱动
- Web 服务用户可写的配置目录与数据目录

## 安装

1. 将本目录部署到 Web 服务器，配置站点及 PHP。
2. 创建数据库，或在安装时选择 SQLite。
3. 配置目录权限，确保 Web 服务用户可以写入 `config/` 和数据目录。
4. 在浏览器中访问站点，按安装向导设置管理员账号、数据目录和数据库。
5. 安装完成后，在管理设置中选择 Cron 后台任务，并配置每 5 分钟执行一次 `cron.php`。

WebDAV 地址：

```text
https://你的域名/remote.php/dav/files/用户名/
```

## 维护

配置文件为 `config/config.php`，命令行管理入口为 `occ`。升级前请备份配置、数据库和数据目录，并确认升级不会覆盖本版本的精简与修改。
